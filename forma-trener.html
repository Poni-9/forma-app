🟠 Strava povezava

Kako se povežem? (enkratna nastavitev, ~5 min)
  1. Pojdi na strava.com/settings/api in ustvari aplikacijo (ime poljubno, kategorija "Training").
  2. Pod Authorization Callback Domain vpiši localhost.
  3. Prepiši Client ID in Client Secret spodaj in klikni Poveži.
  4. Odpre se Strava — potrdi dostop. Preusmerilo te bo na "localhost" (stran se ne odpre — to je v redu!). Iz naslovne vrstice skopiraj cel naslov (ali samo kodo za code=) in jo prilepi nazaj sem.
⚠️ Ta napredna pot pošilja zahtevke prek javnega CORS posrednika — če je le mogoče, uporabi ⭐ povezavo na en klik (žetoni ostanejo na strežniku).

Pozor: Strava od junija 2026 za API dostop zahteva Strava naročnino. Iz brskalnika gre prek javnega proxyja (CORS). Če nimaš naročnine, uporabi Intervals.icu spodaj — je brezplačen.

📈 Intervals.icu brezplačno — najboljša pot brez Strava naročnine

⚠️ Najpogostejša napaka: Intervals.icu je samo posrednik — vožnje vanj prihajajo s tvoje ure/naprave. Če je tvoj Intervals račun nov (prazen), najprej opravi 2. korak, sicer ni česa uvoziti.
  1. Ustvari račun na intervals.icu — Google prijava, 30 sekund.
  2. Poveži vir voženj: na intervals.icu odpri ⚙️ Settings → Connections → poveži Garmin / Wahoo / Suunto / Coros / Polar ali Stravo. Počakaj minuto-dve, da se v Intervals prikažejo tvoje aktivnosti.
  3. API dostop: Settings → čisto na dnu Developer Settings → pri API Key klikni Generate in ključ kopiraj.
  4. Athlete ID piše tik nad ključem (oblika i12345) — ali v naslovu strani intervals.icu/athlete/i12345/…
  5. Oboje prilepi spodaj → Poveži. Od takrat se vožnje uvažajo same (vsake 3 minute), FTP in cone pa prevzamem iz Intervals.
⚠️ Če tvoja ura sinhronizira neposredno prek Garmin povezave, Garmin teh podatkov ne dovoli deliti prek API-ja — v Intervals poveži Stravo (Garmin → Strava → Intervals) in izklopi Garmin povezavo.
Nimaš športne ure? Nič hudega — aktivnosti dodaš s 📸 screenshotom (AI prebere vse) ali ročno v zavihku Aktivnosti.

Enkratno: brezplačen račun na jsonbin.io → API Keys → Master Key prilepi sem. Kodo, ki jo dobiš, prilepi še v aplikacijo KalorijeAI na telefonu — plan in spremembe se potem prenašajo v obe smeri.
